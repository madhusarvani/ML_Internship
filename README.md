## 📁 Project Structure

### Task 1: Data Analysis & Preprocessing
Exploratory data analysis and data preprocessing techniques.

### Task 2: Feature Engineering
Advanced feature engineering and selection methods.

### Task 3: CNN Image Classification
Convolutional Neural Network implementation for CIFAR-10 image classification.
- **Dataset**: CIFAR-10 (10,000 images, 10 classes)
- **Model**: Custom CNN with batch normalization and dropout
- **Accuracy**: High performance classification with visualization

### Task 4: Recommendation System
Collaborative filtering and matrix factorization-based recommendation system.
- **Algorithms**: 
  - User-Based Collaborative Filtering
  - Item-Based Collaborative Filtering
  - SVD (Singular Value Decomposition)
  - NMF (Non-negative Matrix Factorization)
- **Dataset**: MovieLens 100K
- **Evaluation Metrics**: RMSE, MAE, Precision@5, Recall@5

## 🚀 Getting Started

### Prerequisites
- Python 3.9 or higher
- Virtual environment (venv/conda)

### Installation

```bash
# Clone the repository
git clone https://github.com/madhusarvani/ML_Internship.git
cd ML_Internship

# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Windows:
venv\Scripts\activate
# On macOS/Linux:
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt
```

### Running the Projects

Open Jupyter notebooks:
```bash
jupyter notebook
```

Then navigate to the desired task notebook:
- `task1.ipynb` - Data Analysis
- `task2.ipynb` - Feature Engineering
- `task3.ipynb` - CNN Image Classification
- `task4/recommendation_system.ipynb` - Recommendation System
